- `CODEX_BRIEF.md`: full build instruction and milestones.

Use a new GitHub repository `spelling-quest`. The repo should contain the starter pack files; Codex will add the actual application code.

Target devices: Android tablet (Chrome), Mac (Chrome/Safari), Windows laptop (Chrome/Edge). iPad is not a target requirement.
