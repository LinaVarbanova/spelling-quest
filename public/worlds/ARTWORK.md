# Fairy realms artwork

`fairy-realms.webp` is original artwork generated for Spelling Quest using OpenAI ImageGen on 2026-11-07. It depicts one connected fictional continent with six regional viewports. The user’s supplied screenshot informed the desired atmosphere and realm subjects; no third-party source images were copied into the asset. No franchise characters, logos, external image URLs, paid runtime APIs or additional asset downloads are used.

The original generated PNG is retained separately in the creation workspace. The production file is a WebP conversion (1536 × 1024) with no compositing or added text. `WorldArt` frames its six regions using SVG viewports; one cached file serves the map, quest and reward screens.
